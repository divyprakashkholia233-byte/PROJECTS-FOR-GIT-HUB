# Spotify Artist Search & Album Display

A web application that allows users to search for Spotify artists and view their albums through a simple and responsive interface.

## Features

- 🔎 Search for Spotify artists
- 🎵 Display artist information
- 💿 Display albums associated with an artist
- 📱 Responsive user interface
- ⚡ Built with HTML, CSS, and JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Spotify Web API
