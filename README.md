# Spotify Artist Search & Album Display

A web application that allows users to search for Spotify artists and view their albums through a simple and responsive interface.

## Features

- 🔎 Search for Spotify artists
- 🎵 Display artist information
- 💿 Display albums associated with an artist
- 📱 Responsive user interface
- ⚡ Built with HTML, CSS, and JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Spotify Web API

## Project Structure

```text
Spotify Artist Search + Album Display app/
├── index.html
├── style.css
└── script.js
```
## How to Use

1. Open the application in a web browser.
2. Enter the name of an artist in the search box.
3. Click the **Search** button.
4. Browse the artist's albums displayed on the page.

## Purpose

This project was created to practice web development, JavaScript, API integration, and dynamic webpage content.
